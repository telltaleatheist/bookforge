BookForge Reader

Reads web pages aloud through a Crucible inference server.

Crucible servers

Speech comes straight from a Crucible — BookForge does not have to be running. Copy a connect code from that server's operator page (Copy connect code), or from BookForge's Settings → Crucible, and paste it here. One server is selected at a time; everything this extension reads aloud goes to that one.

The code carries the server's name, its address and its token. Chrome asks for permission to reach that address the first time — that prompt is the extension asking to talk to your own machine, and reading will not work without it.

Voice

Pick a server first. The list comes from that server, and each voice brings its own engine — there is nothing else to choose.

A voice on a card is a card nobody else can use. When this long passes with nothing read, the extension unloads it. Loading it again costs the wait once.

Playback

On: a paragraph waits until enough of it has arrived to play straight through, so the read never stops mid-sentence — at the cost of a wait before the first word.
Off (fast start): audio starts after about a second, played as it arrives. First words come almost immediately; if the server falls behind, playback can pause mid-read until it catches up.

How fast the audio is PLAYED, pitch preserved. It is not a request to the server: nothing in Crucible's speech wire carries a speaking rate, and a voice speaks at the pace it was trained at.

Tab recorder

Recording captures a tab's audio and hands the raw samples to BookForge, whose ffmpeg writes the FLAC — so it needs the app running, and its own address below. This is NOT the speech server.

A local BookForge needs no token — this extension is trusted automatically. Only fill this in when recording to BookForge on another machine; find it in that machine's config:
macOS: ~/Library/Application Support/bookforge-app/tts-api.json
Windows: %APPDATA%/bookforge-app/tts-api.json

A folder on the machine running BookForge, not on this one. ~ means that machine's home folder, on Windows too. It is created if it doesn't exist; a relative path is refused. Recordings land here as <page title>-<timestamp>.flac with a .json sidecar.
